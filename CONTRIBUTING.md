# Как помочь проекту

Спасибо за интерес! Вот как можно участвовать.

## Сообщить о баге

Открой issue с описанием:
- ОС и версия Python
- Шаги воспроизведения
- Что ожидал vs что получил
- Скриншоты для UI-проблем

## Предложить функцию

Открой issue с меткой `enhancement`. Опиши:
- Какую проблему решает
- Как видишь API
- Пример использования

## Pull request

1. Форкни репозиторий
2. Создай ветку: `git checkout -b feature/крутая-штука`
3. Внеси изменения
4. Проверь локально: `python -m neurocore.gui`
5. Коммит с понятным сообщением
6. Push и открой PR

## Стиль кода

- PEP 8, отступы 4 пробела
- Type hints приветствуются
- Комментарии на русском или английском

## Свой инструмент

Создай файл `neurocore/tools/builtin/my_tool.py`:

    from ..base import Tool

    class MyTool(Tool):
        name = "my_tool"
        description = "Что делает"
        parameters = {"arg1": "описание"}

        def run(self, arg1: str) -> str:
            return f"результат: {arg1}"

Зарегистрируй в `neurocore/tools/builtin/__init__.py`.

## Лицензия

Проект распространяется под проприетарной лицензией.
Отправляя Pull Request, ты передаёшь все права на изменения Автору проекта.
