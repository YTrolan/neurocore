🧠 NeuroCore

Автономный AI-агент на базе DeepSeek. 36 инструментов. Нативный GUI.

✨ Возможности

  • 💬 Чат с DeepSeek — V4 Pro / Flash / Reasoner
  • 🛠️ 36 инструментов — файлы, shell, интернет, GUI-контроль, браузер
  • 📝 Code Panel — живая панель кода справа (как в Cursor/Codex): подсветка синтаксиса, номера строк, авто-открытие файлов
  • 🔍 DeepSeek Search — встроенный поиск на Flash (3 сек)
  • 🖥️ Управление ПК — скриншоты, клики, окна (pyautogui)
  • 🌐 Автоматизация браузера — Playwright + Chrome
  • 🎨 Генерация картинок — Pollinations (бесплатно)
  • 🔐 Авто-токен — забирает userToken из Chrome
  • 📁 Многосессионный чат — история сохраняется
  • 🎭 Три режима доступа — только чтение / workspace / полный
  • ⚙️ Папка сохранения — файлы агента в выбранной директории
  • ⌨️ Палитра команд — Ctrl+K

📸 Скриншоты

Чат и Code Panel

Слева — диалог с агентом. Справа — панель кода с подсветкой, которая автоматически открывает файлы, созданные агентом.

Вкладка «Траектория»

Все вызовы инструментов пошагово: что вызвано, с какими аргументами, какой результат вернул.

Настройки

  • Аккаунт — токен DeepSeek
  • Модели — что показывать в списке
  • Пресеты — сохранённые системные промпты
  • Хранилище — папка сохранения файлов, сессии
  • О программе

🚀 Быстрый старт

git clone https://github.com/YTrolan/neurocore.git
cd neurocore
pip install -e .
python -m neurocore.gui

Подробно — docs/installation.md.

🔑 Токен DeepSeek

Три способа:

  1. Автоматически из Chrome (рекомендую) — Настройки → «Получить токен». Скрипт скопирует профиль Chrome и заберёт userToken.
  2. Переменная окружения — set DEEPSEEK_TOKEN=...
  3. Файл — ~/.neurocore/token.txt
