## 📚 Использованные библиотеки и сервисы

Проект построен на открытых технологиях. Огромная благодарность:

### Основные

- **[DeepSeek](https://deepseek.com)** — AI-модели (V4 Pro, Flash,
  Reasoner), встроенный web-search
- **[OpenDeep](https://github.com/cmpdchtr/OpenDeep)** (автор:
  [@cmpdchtr](https://github.com/cmpdchtr)) — неофициальный Python-клиент
  для DeepSeek API
- **[PySide6](https://doc.qt.io/qtforpython/)** — GUI-фреймворк (Qt for Python)

### Инструменты

- **[Playwright](https://playwright.dev)** — автоматизация браузера
- **[Pollinations](https://pollinations.ai)** — бесплатная генерация
  изображений
- **[PyAutoGUI](https://github.com/asweigart/pyautogui)** (автор:
  [@asweigart](https://github.com/asweigart)) — управление мышью и
  клавиатурой
- **[pygetwindow](https://github.com/asweigart/PyGetWindow)** — управление
  окнами Windows
- **[pyperclip](https://github.com/asweigart/pyperclip)** — буфер обмена
- **[Pillow](https://python-pillow.org)** — обработка изображений
- **[requests](https://requests.readthedocs.io)** — HTTP-клиент
- **[curl_cffi](https://github.com/yifeikong/curl_cffi)** — обход
  Cloudflare, TLS-фингерпринт
- **[wasmtime-py](https://github.com/bytecodealliance/wasmtime-py)** — WebAssembly
  runtime (используется curl_cffi)
- **[pywinpty](https://github.com/andfoy/pywinpty)** — PTY для встроенного
  терминала
- **[pyte](https://github.com/selectel/pyte)** — эмуляция терминала

### Инфраструктура

- **[PyInstaller](https://pyinstaller.org)** — сборка `.exe`
- **[GitHub](https://github.com)** — хостинг репозитория

## 🤝 Как попасть в список

Если ты внёс вклад в проект (код, идею, баг-репорт, документацию) —
создай Pull Request или открытый Issue. Значимые вклады
будут добавлены сюда.
