# Security Policy

## Supported Versions

Актуальные версии NeuroCore, для которых выпускаются обновления безопасности:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |
## Известные ограничения

NeuroCore использует неофициальный клиент [OpenDeep](https://github.com/cmpdchtr/OpenDeep) для доступа к DeepSeek через веб-сессию. Это значит:

- **Токен DeepSeek хранится локально** (`~/.neurocore/token.txt` или в системном keyring)
- **Инструменты агента** (shell, файловые операции) выполняются от имени вашего пользователя ОС
- **Режим «Полный доступ»** в приложении даёт агенту неограниченные права — используйте только с доверенными промптами

## Что НЕ является уязвимостью

- Срабатывание shell-команд агента — это ожидаемое поведение, если пользователь дал задачу
- Отказ модели отвечать на определённые запросы
- Проблемы со стабильностью неофициального API OpenDeep
