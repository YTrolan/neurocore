# Использование

## Запуск

    python -m neurocore.gui

## Основы чата

Пиши в поле ввода и жми Enter.

### Модели

Переключение — в выпадающем меню справа снизу:

| Модель | Для чего | Скорость |
|---|---|---|
| `deepseek-v4-pro` | Сложные задачи, код | Медленно (5-15с) |
| `deepseek-v4-flash` | Простое, поиск | Быстро (2-4с) |
| `deepseek-reasoner` | Математика, логика | Средне |

## Права доступа

Кнопка-пилюля слева снизу. Определяет что может агент:

| Режим | Что может |
|---|---|
| **Только чтение** | Читать файлы, бродить по сайтам |
| **Запись в workspace** | Писать файлы внутри workspace |
| **Полный доступ** | Всё: shell, системные команды |

По умолчанию — **Запись в workspace**.

## Примеры запросов

### Файлы

    › создай файл test.txt с текстом привет
    › прочитай все .py файлы в текущей папке
    › найди все TODO в проекте
    › сколько строк в gui.py

### Интернет

    › какая сейчас погода в Москве
    › найди в интернете кто такой Пушкин
    › открой wikipedia.org/wiki/Python и дай первые 300 символов

### Управление ПК

    › сделай скриншот экрана
    › покажи список всех открытых окон
    › открой блокнот и напиши "привет"
    › найди на wildberries свитшот

### Код

    › посчитай 12345 * 6789
    › создай простую программу на Python и запусти
    › захешируй файл pyproject.toml sha256

### Картинки

    › нарисуй кота в космосе
    › сгенерируй логотип: синий круг с буквой N

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Enter` | Отправить |
| `Shift+Enter` | Новая строка |
| `Ctrl+N` | Новая сессия |
| `Ctrl+K` | Палитра команд |
| `Ctrl+B` | Панель инструментов |
| `Ctrl+`` | Терминал |
| `Ctrl+,` | Настройки |

## Сессии

- **Новая** — плюс в sidebar
- **Переключение** — клик по сессии
- **Переименовать** — правый клик → Переименовать
- **Удалить** — правый клик → Удалить
- **Поиск** — Ctrl+F в sidebar

Хранятся в `~/.neurocore/sessions/*.json`.

## Терминал

В правой панели — вкладка **Терминал**. Работает как обычный shell.
Можно выбрать оболочку: cmd, PowerShell, Git Bash, WSL.

## Настройки

Ctrl+, — открывает overlay с вкладками:

- **Аккаунт** — токен DeepSeek
- **Модели** — какие показывать в списке
- **Пресеты** — сохранённые системные промпты
- **Хранилище** — где лежат сессии
- **О программе** — версия
